# PROG6112 - Exam Preparation Repository

Welcome to my PROG6112 Exam Preparation Repository! This repository contains my complete solutions, mock tests, and study materials for the Programming 1B exam. 

To make navigation easy, every exam year has its own dedicated folder. 

## 🗺️ How to Navigate This Repository

Every exam folder (e.g., `2022Exam`, `2023Exam`, `2024Exam`) follows the exact same structure:

1. **The Code Folders (Q1, Q2, Q3):** Inside the year folder, you will find separate sub-folders for each question (e.g., `2022ExQ1`, `2022ExQ2`). These contain the actual NetBeans projects with the complete, working source code and answers.
2. **The `README.md` File:** Inside the year folder, there is a `README.md` file. This document explains what the exam question was asking for, lists the project structure, and includes **screenshots of the actual exam paper questions and rubrics**.
3. **The Cheat Sheet:** The `ProgCheetSheet` folder contains a comprehensive, searchable text-based cheat sheet covering all Java syntax, loops, arrays, GUI boilerplate, File I/O, and JUnit tests.

## 🚀 How to Run the Code

1. Open **Apache NetBeans**.
2. Go to `File` -> `Open Project`.
3. Navigate to the specific folder for the question you want to run (e.g., `2022Exam/2022ExQ1`).
4. Ensure the "Main Class" is set correctly (usually the GUI form or the `Main`/`QuestionX` class).
5. Click the **Run** button (or press `F6`).
